# دليل صوت+ للمستخدم المتقدّم

هذا الدليل مخصّص للمستخدم المتقدّم والتثبيت اليدوي وحل مشاكل الشبكة. إذا كنت
تريد الخطوات الأساسية فقط فابدأ من [الملف الرئيسي](../README.ar.md).

## التثبيت اليدوي

### تطبيق الأندرويد

نزّل ملف APK الجاهز من صفحة الإصدارات:

- [أحدث إصدار](https://github.com/apot4711-web/sawt-plus/releases/latest)
- [تحميل `sawt-plus.apk`](https://github.com/apot4711-web/sawt-plus/releases/latest/download/sawt-plus.apk)

افتح الملف على الهاتف، واسمح للمتصفح أو مدير الملفات بتثبيت التطبيقات من هذا
المصدر. إذا ظهر تحذير Play Protect اختر **تثبيت على أي حال**.

> ملف APK موقّع بمفتاح التطوير (debug) وهو مناسب للتثبيت اليدوي والتجربة. لا
> يحتاج التطبيق إلى حساب أو إنترنت، فقط إلى شبكة محلية مشتركة مع الحاسوب.

إذا كان لديك ADB وملف APK محفوظ على الحاسوب:

```bash
adb install -r sawt-plus.apk
```

يتطلب التطبيق أندرويد 5.0 (API 21) أو أحدث.

### حاسوب لينكس

المتطلبات:

- لينكس بنظام **x86_64**.
- PipeWire أو PulseAudio، مع الأمر `pactl` في `PATH`.
- (اختياري) `avahi-browse` لتحسين الاكتشاف.

على فيدورا:

```bash
sudo dnf install pulseaudio-utils avahi-tools
```

على دبيان/أوبونتو:

```bash
sudo apt install pulseaudio-utils avahi-utils
```

نزّل الملف التنفيذي الجاهز إلى مجلدك المحلي:

```bash
mkdir -p ~/.local/bin
curl -fL -o ~/.local/bin/sawt \
  https://github.com/apot4711-web/sawt-plus/releases/latest/download/sawt-linux-amd64
chmod +x ~/.local/bin/sawt
sawt version
```

إذا ظهر `sawt: command not found` فأضف المجلد إلى `PATH`:

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

لا تحتاج إلى Go أو Android SDK لتشغيل البرنامج.

بديل: استنسخ المستودع وشغّل الملف التنفيذي مباشرة:

```bash
git clone https://github.com/apot4711-web/sawt-plus.git
cd sawt-plus
./bin/sawt-linux-amd64 version
```

## التشغيل والاقتران

1. افتح تطبيق **صوت+** على الهاتف.
2. اضغط **تشغيل الخدمة** واسمح بإذن الميكروفون.
3. لاحظ رمز الاقتران المكوّن من ٦ أرقام، وابقِ التطبيق يعمل في الخلفية.
4. على الحاسوب شغّل:

```bash
sawt web
```

سيفتح المتصفح على `http://127.0.0.1:8787`. اختر الهاتف من القائمة، أدخل رمز
الاقتران، ثم ابدأ البث. بعد الاقتران الأول يصبح الاتصال تلقائيًا.

بديل من الطرفية:

```bash
sawt discover
sawt pair 192.168.1.42:8765 123456
```

استبدل العنوان والرمز بما يظهر عندك.

## اختيار الميكروفون

سيُنشئ الحاسوب مصدرًا صوتيًا باسم `sawt-plus`. اختره كميكروفون في تطبيق
الاجتماعات أو التسجيل. للتحكم في مستوى الصوت اختر **مستوى الصوت** داخل
التطبيق، أو استخدم:

```bash
sawt gain 1.5x
sawt mute on
```

إذا لم يظهر المصدر، ثبّت `pavucontrol` وافتحه للتأكد من اختيار
**Sawt+** كمصدر افتراضي.

## التحديث والإزالة

- **تحديث التطبيق**: نزّل أحدث APK ثم ثبّته فوق النسخة الحالية.
- **إزالة التطبيق**: `adb uninstall com.sawtplus.app` أو من إعدادات أندرويد.
- **إزالة برنامج الحاسوب**: احذف `~/.local/bin/sawt`، واختياريًا
  `~/.config/sawt-plus`.

## التحقق من سلامة الملفات

نزّل كل ملفات الإصدار إلى المجلد نفسه، ثم شغّل:

```bash
sha256sum -c SHA256SUMS
```

إذا استنسخت المستودع كاملًا، يعمل الأمر نفسه من جذر المستودع.

## مرجع سطر الأوامر

```console
$ sawt help
```

| الأمر | الوصف |
| --- | --- |
| `daemon` | تشغيل الخادم بلا واجهة وواجهة الويب المحلية في المقدمة. |
| `web [--no-open]` | فتح واجهة المتصفح (يشغّل الخادم عند الحاجة). |
| `status [--json]` | عرض حالة البث والجهاز ومستوى الصوت والكتم. |
| `logs [-n N]` | عرض أحدث أسطر سجل الخادم. |
| `discover [--timeout 3s]` | البحث عن أجهزة Wi-Fi وUSB/ADB. |
| `pair TARGET CODE` | الاقتران عبر `host:port` والرمز المكوّن من ٦ أرقام. |
| `pair --no-connect TARGET CODE` | الاقتران دون بدء البث. |
| `unpair [TARGET]` | نسيان اقتران محفوظ (الافتراضي: الجهاز الحالي). |
| `connect [TARGET]` | الاتصال والبث (عنوان، اسم محفوظ، أو `adb:SERIAL`). |
| `disconnect`، `stop` | إيقاف البث. |
| `gain 1.5x` | ضبط مستوى الصوت في الحاسوب (`0`..`8`، `0%`..`800%`). |
| `mute [on\|off]` | كتم الميكروفون، أو التبديل دون وسيط. |
| `shutdown`، `quit` | إيقاف خادم يعمل في الخلفية. |
| `adb <cmd>` | بديل ADB: `devices`، `pair`، `connect`، `disconnect`، `run`، `install`. |
| `version` | طباعة الإصدار. |

معظم الأوامر تشغّل `sawt daemon` في الخلفية (منفصلًا، والسجل في
`~/.config/sawt-plus/daemon.log`) إذا لم تكن الواجهة متاحة. اضبط
`SAWT_NO_AUTOSTART=1` لطلب خادم صريح.

## الاكتشاف والجدار الناري

يجرّب الاكتشاف ثلاث طبقات ويدمج النتائج:

1. mDNS من Go (`_sawtplus._tcp`).
2. `avahi-browse` على الأنظمة التي تحتويه.
3. مسح نشط للشبكة المحلية `/24` على منفذ TCP رقم 8765، ويتأكد من خادم
   WebSocket قبل الإبلاغ عن الجهاز.

تُدمج الأجهزة المتصلة عبر USB/ADB في القائمة نفسها وتُوسم `USB/ADB`؛ أما
أجهزة Wi-Fi فتُوسم `Wi-Fi`.

إذا لم يجد `discover` شيئًا بينما يرى `avahi-browse -rt _sawtplus._tcp` الهاتف،
فالمرجّح أن جدار الحماية على الحاسوب يحجب mDNS عن عملية Go. اسمح بمنفذ UDP
5353، مثلًا:

```console
# firewalld
$ sudo firewall-cmd --add-service=mdns
$ sudo firewall-cmd --runtime-to-permanent

# ufw
$ sudo ufw allow 5353/udp
```

يعمل المسح النشط دون استثناء mDNS، ما دام الهاتف يقبل الاتصالات على المنفذ
8765 في الشبكة المحلية.

## مستوى الصوت

يطبّق الحاسوب كسبًا رقميًا داخل الخادم، وللتطبيق شريط **مستوى الصوت** خاص به
يضاعف العينات الملتقطة قبل إرسالها. التحكمان مستقلان: اترك أحدهما عند 1.00×
واضبط الآخر. كلاهما مسمّى "مستوى الصوت" / "Input level" في الواجهة لتجنّب
المصطلح التقني "gain" في النصوص الموجّهة للمستخدم.

## بديل USB/ADB

Wi-Fi هو النقل المقصود، لكن ADB يبقى يعمل عندما يكون الجهازان على شبكتين
مختلفتين أو عندما تكون Wi-Fi غير مستقرة.

1. فعّل تصحيح USB على الهاتف وصِل الكابل.
2. تحقق من الجهاز: `adb devices` (أو `sawt adb devices`).
3. اتصل: `sawt connect adb:SERIAL`، أو شغّل حلقة ADB مباشرة بـ
   `sawt adb run`، أو اختر الجهاز الموسوم `USB/ADB` في قائمة المتصفح.

يوفر التطبيق مقبس ADB منفصلًا (`sawt-plus`) حتى لا يتعارض مع تطبيق
`audiosource` الأصلي.

## تفاصيل تطبيق الأندرويد

- تعرض الشاشة الرئيسية حالة الاتصال والعنوان ورمز الاقتران والنقل
  (Wi-Fi / USB-ADB) ومستوى الصوت والكتم.
- اضغط العنوان لنسخه؛ واضغط مطولًا على رمز الاقتران لنسخه.
- تفتح القائمة (أعلى اليسار) الإعدادات وحول. تستخدم الإعدادات صفوفًا تفتح
  نافذة اختيار للغة (النظام/الإنجليزية/العربية) والثيم (النظام/فاتح/داكن)
  واسم الجهاز الظاهر للحاسوب، إضافة إلى اختيار تحسين البطارية (أندرويد 6.0
  فأحدث).
- اضبط استخدام البطارية على **غير مقيّد** في الأنظمة الصارمة (Realme/Oppo
  وما شابه) حتى لا يوقف النظام خدمة الميكروفون في المقدمة.

## استكشاف الأخطاء

- **لا توجد أجهزة**: تأكد من تشغيل التطبيق على الهاتف ومن وجود الجهازين على
  الشبكة نفسها. راجع ملاحظة الجدار الناري أعلاه. جرّب
  `avahi-browse -rt _sawtplus._tcp`.
- **الجهاز يتطلب اقترانًا**: أدخل الرمز المكوّن من ٦ أرقام الظاهر في التطبيق.
  تنتهي صلاحية الرمز بعد 10 دقائق وقد يتغير إذا أُعيد تشغيل الخدمة.
- **لا صوت في مراقب المتصفح**: ابدأ البث أولًا، وتحقق من أذونات الصوت في
  المتصفح، واستخدم سماعات لتجنّب الصدى.
- **المستوى منخفض**: ارفع مستوى الصوت في الهاتف أو الحاسوب، وليس كليهما؛
  كلاهما مضاعف.
- **يتوقف البث في الخلفية**: عطّل تحسين البطارية للتطبيق.
- **ADB غير موجود**: ثبّت أدوات منصة أندرويد وأعد فحص `adb devices`.
- **ظهور `sawt: command not found`**: أضف `~/.local/bin` إلى `PATH`.
- **صفحة الويب تطلب رمز الوصول المحلي**: افتحها بـ `sawt web` (أو استخدم
  الرابط الذي يطبعه `sawt web --no-open`). يوجد الرمز في
  `~/.config/sawt-plus/api.token` بصلاحية `0600`؛ يستلمه المتصفح مرة واحدة
  ويحفظه في كوكي HttpOnly.

## هيكل المشروع

- `apk/`: ملف APK جاهز للتثبيت.
- `bin/`: ملف لينكس التنفيذي الجاهز.
- `cmd/sawt`: نقطة دخول سطر الأوامر.
- `internal/`: الإعدادات والبروتوكول والاكتشاف والصوت/PipeWire وADB والخادم
  وواجهة HTTP وواجهة الويب المدمجة والعميل.
- `app/`: مصدر تطبيق أندرويد (Java، Material 3).
- `internal/web/dist/index.html`: واجهة المتصفح بلا اعتماديات.

## البروتوكول

البث هو PCM موقّع 16 بت، 48 كيلوهرتز، أحادي، بإطارات كل 20 مللي ثانية عبر
WebSocket: رسائل تحكم نصية وإطارات صوت ثنائية.
