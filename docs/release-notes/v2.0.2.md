# Sawt+ 2.0.2

Sawt+ 2.0.2 brings the new sawt-plus visual identity to the Android app. The app
now uses the navy and emerald palette from the project banners, with matching
light and dark themes and a redesigned launcher icon.

## Changes

- Added a complete light and dark Material 3 palette derived from the Sawt+
  brand: navy surfaces, emerald primary, cyan secondary, and accessible text
  and muted colors.
- Kept Material You dynamic colors in the System theme mode; explicit Light and
  Dark modes use the fixed Sawt+ palette.
- Fixed system status and navigation bar icon contrast, including Android 15
  edge-to-edge behavior.
- Replaced the red launcher icon with the navy/emerald microphone mark,
  including adaptive, monochrome, round, and legacy raster icons.
- Updated the embedded web UI on the PC side with the Sawt+ palette and a
  persisted dark/light theme toggle.
- `versionCode` is now `3`; `versionName` is `2.0.2`.

The pairing protocol and the Go version are unchanged (the daemon and CLI still
report 2.0.0). Updating the phone app does not require re-pairing.

## Downloads

| File | Description |
| --- | --- |
| `sawt-plus.apk` | Android app (Android 5.0 / API 21 or newer), debug-signed. |
| `sawt-linux-amd64` | Static Linux x86_64 daemon and CLI, no Go toolchain needed. |
| `sawt-plus-source.zip` | Complete source tree for this tag (excludes the prebuilt artifacts). |
| `SHA256SUMS` | SHA-256 checksums for the three files above. |

## Notes

- The APK is debug-signed and intended for sideloading/testing, not Play Store
  distribution. It uses the same debug certificate as 2.0.0 and 2.0.1, so it can
  be installed over the previous version.
- Very old devices may not support 48 kHz capture. The 44.1 kHz fallback is not
  part of this release; if a device cannot start the microphone, that is the
  likely cause.
- Wi-Fi audio and pairing run over plaintext `ws://` on the local network. Use a
  trusted network; TLS is planned for a later release.
- Report issues at <https://github.com/apot4711-web/sawt-plus/issues>.

# صوت+ 2.0.2

يقدّم صوت+ 2.0.2 الهوية البصرية الجديدة إلى تطبيق أندرويد. يستخدم التطبيق الآن
لوحة الألوان الكحلية والزمردية من بانرات المشروع، مع ثيمين فاتح وداكن متوافقين
وأيقونة تشغيل مُعاد تصميمها.

## التغييرات

- أُضيفت لوحة ألوان Material 3 كاملة للوضعين الفاتح والداكن مبنية على هوية
  صوت+: أسطح كحلية، ولون أساسي زمردي، ولون ثانوي سماوي، وألوان نص وخافتة
  تحقق تبايناً مناسباً.
- بقيت ألوان Material You الديناميكية في وضع System فقط؛ أما وضعا Light وDark
  الصريحان فيستخدمان لوحة صوت+ الثابتة.
- أُصلح تباين أيقونات شريط الحالة وشريط التنقل، بما في ذلك سلوك Android 15
  في وضع edge-to-edge.
- استُبدلت أيقونة التشغيل الحمراء بشعار الميكروفون الكحلي/الزمردي، مع أيقونات
  adaptive وmonochrome ودائرية وأيقونات PNG القديمة.
- حُدّثت واجهة الويب المدمجة على جهة الحاسوب بلوحة ألوان صوت+ ومبدّل ثيم
  فاتح/داكن محفوظ.
- `versionCode` أصبح `3`، و`versionName` أصبح `2.0.2`.

صيغة الاقتران وإصدار Go دون تغيير (يبقى الخادم وأداة الطرفية عند 2.0.0).
تحديث تطبيق الهاتف لا يتطلب إعادة الاقتران.

## الملفات

| الملف | الوصف |
| --- | --- |
| `sawt-plus.apk` | تطبيق أندرويد (5.0 / API 21 أو أحدث)، موقّع بمفتاح debug. |
| `sawt-linux-amd64` | خادم وأداة سطر أوامر لينكس x86_64 ثابت، بلا حاجة إلى Go. |
| `sawt-plus-source.zip` | شجرة المصدر الكاملة لهذا الإصدار (دون الملفات الجاهزة). |
| `SHA256SUMS` | بصمات SHA-256 للملفات الثلاثة أعلاه. |

## ملاحظات

- ملف APK موقّع بمفتاح debug ومخصص للتثبيت اليدوي والتجربة، وليس للنشر على
  متجر Play. يستخدم شهادة debug نفسها المستخدمة في 2.0.0 و2.0.1، فيمكن تثبيته
  فوق الإصدار السابق.
- قد لا تدعم بعض الأجهزة القديمة جداً التقاط الصوت بتردد 48 كيلوهرتز. بديل
  44.1 كيلوهرتز ليس ضمن هذا الإصدار؛ إذا لم يبدأ الميكروفون على جهاز ما فهذا
  هو السبب المرجّح.
- يعمل صوت Wi-Fi والاقتران عبر `ws://` غير مشفّر على الشبكة المحلية. استخدم
  شبكة موثوقة؛ التشفير (TLS) مخطط لإصدار لاحق.
- أبلغ عن المشاكل في <https://github.com/apot4711-web/sawt-plus/issues>.
