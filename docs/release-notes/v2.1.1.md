# Sawt+ 2.1.1

Sawt+ 2.1.1 fixes the Wi-Fi pairing failure introduced in 2.1.0. **Update the
app and the computer binary together, then pair again once.**

## Critical fix

- 2.1.0 could advertise over mDNS and accept TCP connections on port 8765, but
  the TLS handshake failed on the phone, so every Wi-Fi pairing attempt ended
  with `EOF` / "remote host terminated the handshake".
- The phone now runs a standard blocking `SSLServerSocket` TLS front end
  instead of Java-WebSocket's `SSLSocketChannel2`. Decrypted traffic is
  forwarded to a loopback-only WebSocket server with an internal secret
  header, and the real client IP is preserved for pairing throttling.
- The TLS key is regenerated with `DIGEST_NONE` (the 2.1.0 key was restricted
  to `DIGEST_SHA256`, which AndroidKeyStore cannot use for TLS server auth).
  The legacy key is deleted.

## Re-pair once

The certificate is new, so old pins no longer match:

1. On the phone: **Settings → Unpair all** (or clear the app's data).
2. On the computer: `sawt unpair` (or remove the device from `devices`).
3. Pair again over Wi-Fi with the code shown in the app.

Nothing else in the protocol changed. ADB pairing tokens and audio settings are
unaffected apart from the re-pair.

  daemon and CLI also report `2.1.1`.

# صوت+ 2.1.1

صوت+ 2.1.1 يصلح فشل الاقتران عبر Wi-Fi الذي ظهر في 2.1.0. **حدّث التطبيق
وبرنامج الحاسوب معاً، ثم أعد الاقتران مرة واحدة.**

## إصلاح حرج

- كان 2.1.0 يعلن عن نفسه عبر mDNS ويقبل اتصالات TCP على المنفذ 8765، لكن
  مصافحة TLS كانت تفشل على الهاتف، لذا انتهت كل محاولة اقتران عبر Wi-Fi بـ
  `EOF` أو «أُنهيت المصافحة من الطرف الآخر».
- يشغّل الهاتف الآن واجهة TLS قياسية بـ `SSLServerSocket` بدل
  `SSLSocketChannel2` من Java-WebSocket. يُمرَّر المرور المفكوك إلى خادم
  WebSocket على loopback فقط مع رأس سرّي داخلي، ويُحفظ عنوان العميل الحقيقي
  لتحديد معدّل محاولات الاقتران.
- يُعاد توليد مفتاح TLS بـ `DIGEST_NONE` (مفتاح 2.1.0 كان مقيداً بـ
  `DIGEST_SHA256`، وهو ما لا يستطيع AndroidKeyStore استخدامه لمصادقة خادم
  TLS). ويُحذف المفتاح القديم.

## أعد الاقتران مرة واحدة

الشهادة جديدة، لذا لا تطابق البصمات القديمة:

1. على الهاتف: **الإعدادات ← إلغاء اقتران الكل** (أو امسح بيانات التطبيق).
2. على الحاسوب: `sawt unpair` (أو احذف الجهاز من `devices`).
3. أعد الاقتران عبر Wi-Fi بالرمز الظاهر في التطبيق.

لم يتغيّر شيء آخر في البروتوكول. رموز اقتران ADB وإعدادات الصوت لا تتأثر
سوى بإعادة الاقتران.
