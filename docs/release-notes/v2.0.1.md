# Sawt+ 2.0.1

Sawt+ 2.0.1 improves compatibility with older Android devices. The app now
requires Android 5.0 (API 21) instead of Android 7.0 (API 24), so it can be
installed and used on Android 5.x and 6.x phones.

## Changes

- Lowered the minimum Android version from 7.0 (API 24) to 5.0 (API 21).
- Replaced `java.util.Base64` with `android.util.Base64` so pairing no longer
  crashes on Android 5.x/6.x and Android 7.x.
- Replaced the built-in runtime-permission calls with AndroidX compat calls so
  the app no longer crashes at launch on Android 5.0/5.1.
- Fixed `Map` default-method usage in the pairing throttle on Android 5.x–7.x.
- Guarded newer platform APIs (`FLAG_IMMUTABLE`, foreground-service type,
  battery-optimization settings) and hid the battery-optimization UI below
  Android 6.0.
- `versionCode` is now `2`; `versionName` is `2.0.1`.

The PC side is unchanged: the Go daemon and CLI remain at 2.0.0, and the pairing
token format is identical. Updating the phone app does not require re-pairing.

## Downloads

| File | Description |
| --- | --- |
| `sawt-plus.apk` | Android app (Android 5.0 / API 21 or newer), debug-signed. |
| `sawt-linux-amd64` | Static Linux x86_64 daemon and CLI, no Go toolchain needed. |
| `sawt-plus-source.zip` | Complete source tree for this tag (excludes the prebuilt artifacts). |
| `SHA256SUMS` | SHA-256 checksums for the three files above. |

## Notes

- The APK is debug-signed and intended for sideloading/testing, not Play Store
  distribution. It uses the same debug certificate as 2.0.0, so it can be
  installed over the previous version.
- Very old devices may not support 48 kHz capture. The 44.1 kHz fallback is not
  part of this release; if a device cannot start the microphone, that is the
  likely cause.
- Wi-Fi audio and pairing run over plaintext `ws://` on the local network. Use a
  trusted network; TLS is planned for a later release.
- Report issues at <https://github.com/apot4711-web/sawt-plus/issues>.

# صوت+ 2.0.1

يحسّن صوت+ 2.0.1 التوافق مع أجهزة أندرويد القديمة. أصبح التطبيق يتطلب أندرويد
5.0 (API 21) بدلاً من أندرويد 7.0 (API 24)، فيمكن تثبيته واستخدامه على هواتف
أندرويد 5.x و6.x.

## التغييرات

- خُفّض الحد الأدنى لأندرويد من 7.0 (API 24) إلى 5.0 (API 21).
- استُبدل `java.util.Base64` بـ `android.util.Base64` حتى لا يتعطل الاقتران على
  أندرويد 5.x/6.x وأندرويد 7.x.
- استُبدلت استدعاءات أذونات وقت التشغيل المدمجة باستدعاءات AndroidX المتوافقة
  حتى لا يتعطل التطبيق عند التشغيل على أندرويد 5.0/5.1.
- أُصلح استخدام دوال `Map` الافتراضية في تقييد محاولات الاقتران على أندرويد
  5.x–7.x.
- أُضيفت حماية لواجهات النظام الأحدث (`FLAG_IMMUTABLE`، ونوع خدمة المقدمة،
  وإعدادات تحسين البطارية)، وأُخفي خيار تحسين البطارية قبل أندرويد 6.0.
- `versionCode` أصبح `2`، و`versionName` أصبح `2.0.1`.

جهة الحاسوب دون تغيير: يبقى خادم Go وأداة الطرفية عند 2.0.0، وصيغة رمز
الاقتران نفسها. تحديث تطبيق الهاتف لا يتطلب إعادة الاقتران.

## الملفات

| الملف | الوصف |
| --- | --- |
| `sawt-plus.apk` | تطبيق أندرويد (5.0 / API 21 أو أحدث)، موقّع بمفتاح debug. |
| `sawt-linux-amd64` | خادم وأداة سطر أوامر لينكس x86_64 ثابت، بلا حاجة إلى Go. |
| `sawt-plus-source.zip` | شجرة المصدر الكاملة لهذا الإصدار (دون الملفات الجاهزة). |
| `SHA256SUMS` | بصمات SHA-256 للملفات الثلاثة أعلاه. |

## ملاحظات

- ملف APK موقّع بمفتاح debug ومخصص للتثبيت اليدوي والتجربة، وليس للنشر على
  متجر Play. يستخدم شهادة debug نفسها المستخدمة في 2.0.0، فيمكن تثبيته فوق
  الإصدار السابق.
- قد لا تدعم بعض الأجهزة القديمة جداً التقاط الصوت بتردد 48 كيلوهرتز. بديل
  44.1 كيلوهرتز ليس ضمن هذا الإصدار؛ إذا لم يبدأ الميكروفون على جهاز ما فهذا
  هو السبب المرجّح.
- يعمل صوت Wi-Fi والاقتران عبر `ws://` غير مشفّر على الشبكة المحلية. استخدم
  شبكة موثوقة؛ التشفير (TLS) مخطط لإصدار لاحق.
- أبلغ عن المشاكل في <https://github.com/apot4711-web/sawt-plus/issues>.
