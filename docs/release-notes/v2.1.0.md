# Sawt+ 2.1.0

Sawt+ 2.1.0 is a security release. **Update the app and the computer binary
together:** the Wi-Fi protocol now requires TLS and the ADB transport requires a
pairing token, so old and new versions cannot talk to each other.

## ⚠️ Breaking changes

- **Wi-Fi is now TLS-only (`wss://`).** The phone serves a self-signed
  certificate; the computer pins its SHA-256 fingerprint (shown in
  Settings → Certificate fingerprint). Old binaries cannot connect to the new
  app, and vice versa.
- **ADB now requires a prior Wi-Fi pairing.** The phone's ADB socket demands
  `TOKEN <pairing-token>` before any audio flows. If you have only ever used
  USB, pair once over Wi-Fi first (`sawt pair HOST:PORT CODE`).
- **License changed MIT → GPLv3.** Anyone distributing Sawt+ or modified
  versions must keep the source open.

## Security fixes

- Any app on the phone could previously tap the microphone through the
  unauthenticated ADB socket; the token handshake closes this hole.
- Pairing tokens no longer travel in cleartext over Wi-Fi.
- Certificate pinning (TOFU) on every connect; a mismatched certificate aborts
  the connection before any secret is sent.
- mDNS spoofing can no longer steal the token: rediscovery verifies identity
  with a tokenless TLS handshake. Legacy pairings must re-pair once to
  establish the pin.
- Pairing-code brute force is throttled per address with exponential backoff
  (2s→60s) and a 5-minute lockout after 8 rejections; the phone's
  `retry_after` is honored.
- Microphone capture restarts with backoff after interruptions (for example a
  phone call) instead of dying silently; `startRecording()` failures are
  contained.
- New **Unpair all** in Settings revokes every token and drops live Wi-Fi and
  ADB sessions immediately. Computers must pair again.
- Hardened internals: WebSocket read limits are sized to the negotiated frame
  (was 16 MB); status broadcasts are throttled to 2/sec on the audio path.

## New feature

- **USB hotplug auto-connect:** with the daemon running, plugging in a
  previously paired phone connects automatically. Unplug to disconnect. Only
  ever paired devices; disable with `auto_connect = false`.

## Downloads

| File | Description |

| `sawt-linux-amd64` | Static Linux x86_64 daemon and CLI, no Go toolchain needed. |

## Notes

- The APK is debug-signed and intended for sideloading/testing, not Play Store
  distribution. It uses the same debug certificate as previous releases, so it
  can be installed over 2.0.2.
- After updating, open **Settings → Certificate fingerprint** on the phone the
  first time you connect so the computer can pin the new certificate.
- `versionCode` is now `4`; `versionName` is `2.1.0`. The daemon and CLI now
  also report `2.1.0`.
- Report issues at <https://github.com/apot4711-web/sawt-plus/issues>.

# صوت+ 2.1.0

صوت+ 2.1.0 إصدار أمني. **حدّث التطبيق وبرنامج الحاسوب معاً:** يستخدم نقل
Wi-Fi الآن TLS، ويتطلب نقل ADB رمز اقتران، لذا لا يمكن للإصدارات القديمة
والجديدة التواصل مع بعضها.

## ⚠️ تغييرات كاسرة

- **Wi-Fi أصبح TLS فقط (`wss://`).** يقدّم الهاتف شهادة موقّعة ذاتياً، ويثبّت
  الحاسوب بصمة SHA-256 الخاصة بها (تظهر في الإعدادات ← بصمة الشهادة). لا يمكن
  للبرامج القديمة الاتصال بالتطبيق الجديد والعكس.
- **ADB يتطلب اقتراناً سابقاً عبر Wi-Fi.** يطلب مقبس ADB على الهاتف السطر
  `TOKEN <pairing-token>` قبل تدفّق أي صوت. إن كنت تستخدم USB فقط، اقترن مرة
  واحدة عبر Wi-Fi أولاً (`sawt pair HOST:PORT CODE`).
- **تغيّر الترخيص من MIT إلى GPLv3.** من يوزّع صوت+ أو نسخاً معدّلة عليه إبقاء
  المصدر مفتوحاً.

## إصلاحات أمنية

- كان بإمكان أي تطبيق على الهاتف سابقاً الوصول إلى الميكروفون عبر مقبس ADB
  غير الموثّق؛ وتُغلق هذه الثغرة الآن بمصافحة الرمز.
- لم تعد رموز الاقتران تنتقل غير مشفّرة عبر Wi-Fi.
- تثبيت الشهادة (TOFU) في كل اتصال؛ الشهادة غير المطابقة تُجهض الاتصال قبل
  إرسال أي سر.
- لم يعد انتحال mDNS قادراً على سرقة الرمز: تتحقق إعادة الاكتشاف من الهوية
  بمصافحة TLS بلا رمز. على الاقترانات القديمة إعادة الاقتران مرة واحدة لتثبيت
  الشهادة.
- تخمين رمز الاقتران محدود لكل عنوان بتراجع أُسّي (2s→60s) وقفل 5 دقائق بعد
  8 محاولات مرفوضة، مع احترام `retry_after` من الهاتف.
- تُستأنف إزالة التقاط الميكروفون بتراجع بعد الانقطاعات (كالاتصال الهاتفي)
  بدل التوقف الصامت؛ وتُحتوى أخطاء `startRecording()`.
- زر **إلغاء اقتران الكل** في الإعدادات يلغي كل الرموز ويقطع جلسات Wi-Fi وADB
  الحية فوراً. على الحواسيب إعادة الاقتران.
- تحصين داخلي: حُدّت حدود قراءة WebSocket بحسب الإطار المتفاوض عليه (كانت
  16 ميغابايت)، وخُفّض بث الحالة إلى مرتين/ثانية على مسار الصوت.

## ميزة جديدة

- **اتصال USB التلقائي عند التوصيل:** مع تشغيل الخادم، يؤدي توصيل هاتف مقترن
  سابقاً إلى الاتصال تلقائياً. افصل الكابل للقطع. للأجهزة المقترنة فقط؛ عطّله
  بـ `auto_connect = false`.
