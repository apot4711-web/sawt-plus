# Sawt+ 2.1.2

Sawt+ 2.1.2 fixes the remaining Stop Service and ADB reconnect bugs. Update
the app and the computer binary together; **no re-pairing is needed**.

## Fixes

- **Stop Service no longer crashes.** Closing the TLS/WebSocket server performs
  network I/O, so it now runs on a transport worker instead of the main thread.
  `NetworkOnMainThreadException` is gone.
- **Stop then Start works immediately.** The ADB abstract socket is released
  before the service returns, and a restarted service waits for the previous
  teardown. No more `Address already in use`.
- **The ADB fallback no longer relaunches the app every ~20 seconds.** The
  daemon only starts `MainActivity` when the app process is not running, and
  the activity is `singleTop`, so retries no longer stack activities or pull
  the user back to the app.
- **New Wi-Fi clients always receive `ready` before `stats`.** This removes the
  `unexpected handshake message "stats"` reconnect failure.
- **Clearer discovery.** A stale adb server is restarted automatically, and
  `sawt discover` / `sawt connect` warn about USB debugging and PC Wi-Fi power
  save.

- The APK is signed with the same certificate as previous releases, so it
  installs over 2.1.1. It is now a non-debuggable release build.
  `versionCode` is `6`; `versionName` is `2.1.2`. The daemon and CLI also
  report `2.1.2`.
- The protocol and pairing tokens are unchanged.

# صوت+ 2.1.2

صوت+ 2.1.2 يصلح مشاكل إيقاف الخدمة وإعادة اتصال ADB المتبقية. حدّث التطبيق
وبرنامج الحاسوب معاً؛ **لا حاجة لإعادة الاقتران**.

## الإصلاحات

- **إيقاف الخدمة لم يعد ينهار.** إغلاق خادم TLS/WebSocket يجري عبر خيط نقل
  منفصل بدل الخيط الرئيسي، فاختفى `NetworkOnMainThreadException`.
- **الإيقاف ثم التشغيل الفوري يعمل.** يُحرَّر مقبس ADB قبل عودة الخدمة،
  وتنتظر الخدمة الجديدة انتهاء تفكيك القديمة؛ لا مزيد من
  `Address already in use`.
- **مسار ADB لم يعد يعيد فتح التطبيق كل ~20 ثانية.** لا يفتح الخادم
  `MainActivity` إلا إذا كانت العملية غير شغالة، والنشاط أصبح `singleTop`،
  فلا تتراكم الأنشطة ولا يُسحب المستخدم إلى التطبيق عند كل محاولة.
- **عملاء Wi-Fi الجدد يستلمون `ready` قبل `stats`.** يختفي فشل إعادة الاتصال
  `unexpected handshake message "stats"`.
- **اكتشاف أوضح.** يُعاد تشغيل خادم adb القديم تلقائياً، وتنبّه أوامر
  `sawt discover` / `sawt connect` إلى تصحيح USB وتوفير طاقة Wi-Fi على الحاسوب.
