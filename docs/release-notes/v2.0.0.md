# Sawt+ 2.0.0

Sawt+ turns an Android phone into a wireless microphone for a Linux computer.
This is the first public release: Wi-Fi microphone streaming, USB/ADB fallback,
multi-layer discovery, single-use pairing with per-IP throttling, a local API
token, a headless daemon, an optional browser UI, and a Material 3 app in
English and Arabic.

## Downloads

| File | Description |
| --- | --- |
| `sawt-plus.apk` | Android app (Android 7.0 / API 24 or newer), debug-signed. |
| `sawt-linux-amd64` | Static Linux x86_64 daemon and CLI, no Go toolchain needed. |
| `sawt-plus-source.zip` | Complete source tree for this tag (excludes the prebuilt artifacts). |
| `SHA256SUMS` | SHA-256 checksums for the three files above. |

### Android

Download `sawt-plus.apk`, open it on the phone, allow installs from your browser
or file manager, and choose **Install anyway** if Play Protect warns. Then start
the service, grant microphone permission, and note the 6-digit pairing code.

### Linux

```bash
mkdir -p ~/.local/bin
curl -fL -o ~/.local/bin/sawt \
  https://github.com/apot4711-web/sawt-plus/releases/latest/download/sawt-linux-amd64
chmod +x ~/.local/bin/sawt
sawt version
```

Requirements: PipeWire or PulseAudio with `pactl` in `PATH`. Optional:
`avahi-browse` for better discovery. Run `sawt web` to pair from the browser, or
`sawt discover` and `sawt pair HOST:PORT CODE` from the terminal.

## Verify the download

Place the three files in one directory and run:

```bash
sha256sum -c SHA256SUMS
```

## Notes

- The APK is debug-signed and intended for sideloading/testing, not Play Store
  distribution.
- Wi-Fi audio and pairing run over plaintext `ws://` on the local network. Use a
  trusted network; TLS is planned for a later release.
- The PC applies its own digital input level, and the app has an independent
  input-level slider. Both are multipliers, so adjust one and leave the other at
  1.00×.
- Report issues at <https://github.com/apot4711-web/sawt-plus/issues>.

# صوت+ 2.0.0

يحوّل صوت+ هاتف أندرويد إلى ميكروفون لاسلكي لحاسوب لينكس. هذا أول إصدار عام:
بث الميكروفون عبر Wi-Fi، وبديل USB/ADB، واكتشاف متعدد الطبقات، واقتران
لمرة واحدة مع تقييد المحاولات لكل عنوان IP، ورمز وصول محلي للواجهة، وخادم بلا
واجهة، وصفحة ويب اختيارية، وتطبيق Material 3 بالعربية والإنجليزية.

## الملفات

| الملف | الوصف |
| --- | --- |
| `sawt-plus.apk` | تطبيق أندرويد (7.0 / API 24 أو أحدث)، موقّع بمفتاح debug. |
| `sawt-linux-amd64` | خادم وأداة سطر أوامر لينكس x86_64 ثابت، بلا حاجة إلى Go. |
| `sawt-plus-source.zip` | شجرة المصدر الكاملة لهذا الإصدار (دون الملفات الجاهزة). |
| `SHA256SUMS` | بصمات SHA-256 للملفات الثلاثة أعلاه. |

### أندرويد

نزّل `sawt-plus.apk`، وافتحه على الهاتف، واسمح بالتثبيت من المتصفح أو مدير
الملفات، واختر **تثبيت على أي حال** إذا ظهر تحذير Play Protect. ثم شغّل
الخدمة، واسمح بإذن الميكروفون، ولاحظ رمز الاقتران المكوّن من ٦ أرقام.

### لينكس

```bash
mkdir -p ~/.local/bin
curl -fL -o ~/.local/bin/sawt \
  https://github.com/apot4711-web/sawt-plus/releases/latest/download/sawt-linux-amd64
chmod +x ~/.local/bin/sawt
sawt version
```

المتطلبات: PipeWire أو PulseAudio مع `pactl` في `PATH`. اختيارياً:
`avahi-browse` لتحسين الاكتشاف. شغّل `sawt web` للاقتران من المتصفح، أو
`sawt discover` ثم `sawt pair HOST:PORT CODE` من الطرفية.

## التحقق من التنزيل

ضع الملفات الثلاثة في مجلد واحد ثم شغّل:

```bash
sha256sum -c SHA256SUMS
```

- ملف APK موقّع بمفتاح debug ومخصص للتثبيت اليدوي والتجربة، وليس للنشر على
